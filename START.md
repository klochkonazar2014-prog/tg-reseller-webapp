# Arenda Bot - Инструкция по запуску

## Запуск системы

### 1. Основная система (бот + сервер + туннель)
```bash
python run.py
```
Это запустит:
- Cloudflare Tunnel (публичный доступ)
- Live Server (API на порту 8001)
- Telegram Bot
- Auto-Buyer (мониторинг блокчейна)

### 2. Парсер (синхронизация с MarketApp)
```bash
python parser.py
```
- Синхронизирует подарки, номера и юзернеймы каждые **30 секунд**
- Обновляет базу данных с реальными ценами и сроками аренды
- Запускай отдельно, когда нужно обновить каталог

## Что изменено

### ✅ Номера подарков
Теперь в карточках отображается **полное название** с номером (например, "Party Sparkler #129702")

### ✅ Карточки юзернеймов
Добавлена визуализация для Telegram Username:
- Большой символ **@** в центре
- Синий бейдж с именем юзернейма

### ✅ Парсер
- Интервал синхронизации: **30 секунд**
- Докачивает все типы: подарки, номера, юзернеймы

### ✅ Ручной запуск
Парсер **НЕ** запускается автоматически — только когда ты сам запустишь `python parser.py`
