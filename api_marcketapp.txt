At the moment, this API is free but may be changed in the future.

Follow the Marketapp API channel for the latest news and updates.

Authentication
Endpoints require authentication via API token.

How to authenticate:

Get your API token from the Marketapp
Add Authorization header to your request
Set the header value to your API token (without any prefix like "Bearer")
Example:

Authorization: your_api_token_here
Code Examples
Some endpoints will return a transaction that you need to send to the blockchain yourself. See this example to learn how to do this.
